## Featured Projects

### [StreamTube — Video Sharing Platform Backend](https://github.com/anupjha95581-ai/Backend_YT)

A YouTube-inspired backend focused on modular server architecture and media-oriented APIs. The project includes JWT access and refresh authentication, protected routes, MongoDB integration, aggregation pipelines, and Cloudinary-based media uploads.

**Technologies:** Node.js, Express.js, MongoDB, JWT, Cloudinary

### [Vibration Predictive Maintenance System](https://github.com/anupjha95581-ai/vibration-predictive-maintenance)

An edge-monitoring and predictive-maintenance project for detecting abnormal machine vibration. It combines simulation, CWRU bearing data, ESP32 firmware, Wokwi, MQTT communication, and machine-learning-based alerting workflows.

**Technologies:** Python, Jupyter Notebook, MATLAB, C++, ESP32, MQTT, Wokwi, machine learning

### [8-bit Calculator — Sky130 ASIC Flow](https://github.com/anupjha95581-ai/calculator-sky130-asic)

An 8-bit digital calculator design implemented in Verilog and taken through an open-source RTL-to-GDSII ASIC flow using OpenLane and the SkyWater 130 nm PDK. The project description reports successful DRC and timing signoff checks.

**Technologies:** Verilog, OpenLane, SkyWater 130nm PDK

### [RF Backscatter](https://github.com/anupjha95581-ai/RF_Backscatter)

A project repository combining Python and CSS, focused on RF backscatter-related experimentation and presentation.

**Technologies:** Python, CSS

### [Music App](https://github.com/anupjha95581-ai/Music-App)

A frontend-focused music application interface built with web technologies.

**Technologies:** JavaScript, CSS, HTML

### [IoT Home Automation](https://github.com/anupjha95581-ai/IOT-HOME-AUTOMATION)

An electronics and embedded-systems project for home automation.

## Run Locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/anupjha95581-ai/PORTFOLIO.git
cd PORTFOLIO
```

You can also serve it locally with any static web server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
